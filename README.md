# 🎮 Poke Journey CLI

> Um jogo RPG de Pokémon em terminal desenvolvido em Node.js que recria a experiência clássica dos jogos Pokémon diretamente no console

## ⚠️ Status
**🚧 Em Desenvolvimento** - Atualmente apenas a região de **Kanto** está disponível.

## ✨ Características

### 🎯 Sistema de Batalha
- Batalhas por turnos contra Pokémon selvagens
- Sistema de movimentos com PP (Power Points)
- Cálculo de dano baseado em poder e nível
- Barras de HP visuais e animadas
- IA para controlar Pokémon inimigos

### 🗺️ Exploração
- Navegue pela região de Kanto
- Rotas com encontros aleatórios
- Cidades e localizações icônicas
- Sistema de navegação interativo

### 👤 Gerenciamento
- Crie múltiplos personagens
- Escolha seu Pokémon inicial
- Sistema de equipe
- Persistência de dados

## 🚀 Como Jogar

### Pré-requisitos
- Node.js (v14+)
- npm

### Instalação
```bash
# Clone o repositório
git clone https://github.com/LeandraBordin/poke-journey-cli.git

# Entre na pasta
cd poke-journey-cli

# Instale dependências
npm install

# Inicie o jogo
npm run start
```

## 🎮 Controles
- Digite o número da opção
- Pressione Enter para confirmar
- Navegue pelos menus com números
